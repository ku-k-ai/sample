# C条件の一般化文を作る指示（foldごとに別の入力・会話）

入力は、このfoldのBで使う承認済み参照カードと正式ルールだけ。
対象特許、対象正解、他foldのカード、既存17件の全体要約を見ない。

同じ入力事例で共通して使われた区別を、STEP1 / STEP2_PLAN / STEP2_REVIEW / FINAL_DECISION の4つの短いviewに抽象化する。特許番号・案件固有名称・その入力例・その答えを本文に列挙せず、何を確認・比較するかを書く。

正式ルールは変更しない。例がない領域まで適用範囲を広げない。全域での正しさが不明な優先順位は追加しない。適用範囲や未確定部分は残す。Bと同じ事例を説明できない一般化になったら、その不成立を報告する。

全source_reference_ids / source_case_ids / source_family_idsを別メタデータとして列挙する。このメタデータは分類LLMへの補助文には含めない。文中から特許名を消しても来歴は消えない。

本実験のCは「Bと同じ材料を抽象文だけにした条件」である。Bの方が有利になるようわざと粗く一般化しない。逆にCへ別事例や新知識を追加しない。作成入力・出力を保存して固定する。結果を見てCだけ作り直さない。
