# STEP2（本文確認）プロンプトの差し替え

会社で動いているSTEP2プロンプト（「あなたは、特許の「詳細な説明」を読み、STEP1で分からなかった事実を確認する担当です。」で始まるもの）に対して、次の2か所だけを置き換える。他は変えない。

旧文は画面写真から書き起こしたもの。句読点や改行が実物と違う場合は、意味の同じ行を置き換えること。

---

## 1. 「# 確認事項への答え方」の「確認済み」の行

### 旧
```
- 確認済み：原文で事実を確認できた場合です。「そうである」だけでなく、「そうではない」と明記されている場合も含みます。「確認した事実」と原文の引用を必ず付けてください。
```

### 新
```
- 確認済み：確認事項の中身を、原文で確認できた場合です。「そうである」だけでなく、「そうではない」と明記されている場合も含みます。「確認した事実」と原文の引用を必ず付けてください。
  - 字面ではなく中身で判定してください。用語が違っても、一般的な技術知識で同じものを指すと言えれば同じとして扱います（例：シート・シート状の媒体・用紙・紙・記録媒体、搬送・供給・送り）。
  - 画像形成装置で画像を形成されるシートは、特に断りがなければ用紙として扱ってかまいません。
  - 「確認した事実」に確認事項の中身を書けた場合は、「未確認」にしないでください。
  - 一般知識で補ってはいけないのは、その特許固有の事実（この装置の接続先、この装置の用途など）です。用語の言い換えや、どの装置にも成り立つ技術常識は補ってかまいません。
```

---

## 2. 「# 担当範囲の判定」の「判定対象外」の行

### 旧
```
- 判定対象外：全文を読んでも、今回の対象・機能・手段・用途と担当範囲との具体的なつながりを確認できない。
```

### 新
```
- 判定対象外：確認済みの事実から、今回の対象・機能・手段・用途が、担当範囲の対象・工程とは別物だと言える場合です。その確認済みの事項と原文引用を必ず付けてください。
  確認事項が未確認のまま残っただけの場合は、判定対象外にせず「本文確認が必要」のままにしてください。見つからないことは、別物である根拠になりません。
```

---

## なぜこの2か所か

- ある案件で、確認事項が「〜が画像形成済みの紙であること」だった。STEP2は本文の「画像形成装置において画像が形成された…シート」という段落を自分で引用し、確認した事実にも同じ内容を書いたうえで、「紙であることを明記していない」として未確認にした。→ 1で直す。
- 確認済みが0件のまま、旧定義「全文を読んでも…確認できない」に従って判定対象外にし、正解の候補が選択不可になった。同じプロンプトの後段にある「書かれていなかったことだけで候補を除外しないでください」と矛盾していた。→ 2で直す。
- どちらも、`patent_pipeline/guards.py` の検査でも止める（`validate_review` の判定対象外の条件、`suspicious_unconfirmed`、`build_final_input` の選択可能の範囲）。プロンプトだけに頼らない。

## STEP1側（任意）

確認事項の「判定する条件」は、正式ルールの原文を引用する作りになっている（`freeze_plan` の検査）。そのため「画像形成された紙」のような定義の語がそのまま条件に入り、STEP2が字面で探しにいく。1の差し替えで吸収できるので必須ではないが、STEP1の確認事項の文面（対象）を「〜が、画像形成装置で画像を形成された後の媒体であること」のように中身で書かせると、さらに外れにくい。
