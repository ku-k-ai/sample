この「特許検索式自動提案ツール」の設計について、以下の記事で説明されているARTEXの仕組みを参考に、応用できる部分を検討してほしい。

注目したいのは、対象情報と探索履歴の管理、計画役と実行役の分離、実行結果に基づく再計画。

まず、このプロジェクトの既存仕様・コード・利用する検索DB・検索結果の取得方法を確認したうえで、以下を検討してほしい。

1. 技術要素、同義語、分類、文献と根拠をどう保存・再利用するか。
2. 検索式の版、変更理由、取得結果、取り逃し、ノイズをどう記録するか。
3. 検索結果を根拠に、次に試す検索式の変更をどう選ぶか。
4. 検索構文の正しさと、検索品質をそれぞれどう検証するか。検索件数やLLMの自己評価だけで品質を判定せず、既知関連文献や文献の関連性評価を使う方法を考えること。
5. 調査対象・期間などの固定条件、試行予算、停止条件をどう扱うか。
6. 自動検索が可能な場合と、手動検索結果を取り込む場合で、どこまで実現できるか。

既知関連文献に対する評価と、未知の文献を含む網羅性は区別すること。検索式の調整に使った文献だけで評価が完結しない方法も検討してほしい。

現行案との比較を踏まえ、「採用すると効果がありそうな部分」「今は不要な部分」「実現条件が未確認の部分」を示し、最小構成と評価方法を提案してほしい。複数エージェントやグラフDBを使う必要性も、その効果と実装負担から判断してほしい。

回答は、推奨する構成とその理由を先に短く示し、その後に具体案を説明してほしい。
