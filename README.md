4つの項目を埋めて、そのまま文章にするだけです。
テンプレ
① 目的：〜な状態にしたい（なぜやるか）
② 完了条件：〜ができていれば完了
③ 範囲・優先度：対象は〜、対象外は〜、優先は〜
④ 報告：着手前に〜、〜ごとに報告
風呂掃除の例
① 目的：今夜、家族が気持ちよく入浴できる状態にしたい
② 完了条件：浴槽・床にぬめりと汚れがない／排水口に髪の毛がない／お湯を張れる
③ 範囲・優先度：浴槽 → 床 → 排水口の順。30分以内。
   サッシ・壁のカビは対象外（見つけたら報告だけ）
④ 報告：着手前に手順を見せて。各箇所が終わるたびに写真付きで報告
ポイント
②は「見て確認できる状態」で書く。「きれいに」は人によって基準が違うので、事例のような「水をかけて完了」が起きます。
③は「やらないこと」も書く。これがないと、サッシ10cmを3時間磨くような暴走が起きます。
④は「着手前」を必ず入れる。計画の段階でズレを止めるのがいちばん安上がりです。
仕事の指示でも同じ型が使えます。たとえば「資料作って」は「部長が3分で承認判断できる資料にしたい（目的）／結論・費用・リスクが1枚に載っていれば完了（完了条件）／競合比較は不要、今日中（範囲・優先度）／構成案の段階で一度見せて（報告）」と書き換えられます。
