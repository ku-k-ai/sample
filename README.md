# 特許の届け先分類 v3

## まず見るもの：`verify_CIS01/`

密着イメージセンサ（CIS）の実案件1件を、別のAIでそのまま検証するためのファイルです。

| ファイル | 中身 | 使い方 |
|---|---|---|
| `1_プロンプト全文_CIS01.txt` | 本番用のプロンプト全文（入力埋め込み済み）。LLMは事実だけを出し、届け先は出さない | 本番の形。届け先は `code/route_v3.py` の `decide()` が決める |
| `2_Sonnetの出力_CIS01.json` | 1をSonnetに渡したときの出力 | 比較用 |
| `3_判定結果_CIS01.json` | 2を `decide()` に通した結果（⑫リーダー） | 比較用 |
| `4_判定まで出すプロンプト_CIS01.txt` | 1の末尾に判定手順（手順6）を足した版 | **別のAIに貼るだけで最終判定まで出る**。期待は `最終判定: ⑫リーダー`、`適用した順位: 2` |

別のAIの出力で見るのは次の2つ。
- `場所の担当項目` が `["⑫リーダー"]` か。ここが外れていたら、事実の段階で外れている（本番でも起きる問題）。
- `技術の一致` で⑤低圧電源が true でも正常。低圧電源の技術が関わるのは事実で、場所の担当がいる場合はそちらが先、というのがルール。

## 仕組み

```
LLM（code/prompt_v3.txt）：事実を書き出す（請求物・場所・場所の担当項目・明示記載・技術の一致）
Python（code/route_v3.py の decide）：決まった順番で届け先を決める
  1 明示記載 → 2 場所の担当 → 3 技術（場所が本体共通・限定なしのときだけ）→ 4 残余
  決まった項目が選択可能に無ければ、代用せず自信無＋本来の届け先
```

CIS専用の処理は無い。同じコードが、本体電源や単体電源装置の特許では⑤低圧電源を選ぶ。

## `code/`

- `prompt_v3.txt` 事実整理プロンプト（テンプレート）
- `route_v3.py` 判定コード、プロンプト生成、既存パイプラインJSONからの入力作成
- `rules_E.json` Eドメインのルール表（既存の列のまま）
- `test_decide.py` 判定の分岐テスト23本（`python test_decide.py`）
- `cases/` 検証ケース14件、`prompts/` 生成したプロンプト、`results/` Sonnetの出力
- `evaluate.py` 採点（`python evaluate.py`）

## 検証ケースについて（注意）

14件のうち、実案件はCISの1件だけ（01・02・14はその変形）。残り11件は、判定が割れそうな境目を試すために作った**架空の特許**で、正解も作成者の読み。うち5件（05・06・08・10・13）は仮定。

| # | 本物/架空 | 内容 | 期待 | 結果 |
|---|---|---|---|---|
| 01 | 本物 | CIS内の基板間給電回路 | ⑫リーダー | ✓ |
| 02 | 本物（改） | 01でリーダーが選択不可 | 自信無（本来＝⑫リーダー） | △ 自信無で止まるが本来の届け先は出ず |
| 14 | 本物（改） | 01を請求項だけで | ⑫リーダー | ✓ |
| 03 | 架空 | 本体電源の間欠発振 | ⑤低圧電源 | ✓ |
| 12 | 架空 | 単体の電源装置 | ⑤低圧電源 | ✓ |
| 04 | 架空 | 定着ヒータのフリッカ | ⑩定着制御 | ✓ |
| 11 | 架空 | 転写の高圧電源 | ⑥高圧電源 | ✓ |
| 07 | 架空 | ADFの重送検知 | ⑫リーダー | ✓ |
| 09 | 架空 | 給紙デッキのエアー給紙 | ⑧シート搬送制御 | ✓ |
| 05 | 架空 | レジローラのモータ | ⑦モータ制御（仮定） | ✓ |
| 06 | 架空 | 搬送路のメディア検知 | ⑪センサ制御（仮定） | ✓ |
| 08 | 架空 | 定着近傍のファン | ⑨FAN制御（仮定） | ✓ |
| 10 | 架空 | CISのLED駆動 | ⑫リーダー（仮定） | ✓ |
| 13 | 架空 | ポリゴンの速度制御 | ③スキャナ制御（仮定） | 未実行 |

`results/` はプロンプトに「場所の担当項目が表に無い」欄を足す前の出力。02の失敗（担当項目を空で返した）を受けて欄を足したが、その効果はLLMで再実行していない。

## 次にやること

1. 仮定の5件と丁合機の件に、社内の正解を付ける。
2. 正解が技術型（低圧電源・高圧電源・モータ・FAN・センサ）の実案件を流す。
3. 同じ入力を数回流し、事実のぶれ（特に場所の担当項目が空になる頻度）を測る。
